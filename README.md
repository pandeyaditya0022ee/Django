# 🎬 Metflix

A Netflix-inspired movie web application built with **Django**.

### Features

* 🎥 Browse movies and view details
* 🔐 User registration and login
* 📌 Personal watchlist
* 🎭 Movie genres
* 🖼️ Movie poster uploads
* 🎨 Tailwind CSS styling
* 🐳 Docker support

### Tech Stack

**Python · Django · SQLite · Tailwind CSS · Pillow · Docker**

### Run

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open `http://127.0.0.1:8000/`

**Learning project focused on Django MVT, ORM, authentication, forms, and database relationships.**




# 🐦 Twitter Clone

A simple Twitter-inspired social media web application built with **Django**.

### Features

* 👤 User authentication
* 📝 Create and manage tweets
* ❤️ Social interaction functionality
* 🖼️ Image/photo support
* 🌐 Django templates
* 🗄️ SQLite database

### Tech Stack

**Python · Django · SQLite · HTML · CSS**

### Run

```bash
python manage.py migrate
python manage.py runserver
```

Open `http://127.0.0.1:8000/`

**Learning project focused on Django models, views, templates, authentication, and CRUD operations.**
